# Journal-independent archive scope

This repository is designed for citation from any appropriate research venue. It is not endorsed by, accepted by, or affiliated with a particular journal.

## Unchanged primary evidence

The `raw_reports/` and `historical_comparator_26pairs/` files, plus all files under `experimental_runner_snapshots/`, are intentionally preserved byte-for-byte from the prior checked release. Their original labels, environment-variable names and machine-specific setup are **historical implementation details**, not requirements for publication in any venue. Renaming them would obscure provenance and could invalidate source-integrity checks.

## Public-facing names

All top-level supplementary outputs use the prefix `TOULOUR_INDEX_S3_` rather than a journal or draft-version prefix. Both public verification commands operate from the repository root.

## Evidence boundaries

Saved-results verification is available without the lexicon. Historical runner snapshots are inspectable, but cannot fully replay without code and data intentionally excluded from this repository. No journal acceptance or full independent replay is claimed.
